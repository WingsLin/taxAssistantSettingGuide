零、先判断：本指引是否适用

对号入座：属于"适用"的，按本指引逐项设置即可解决；属于"需提单"的，靠设置解决不了，请直接反馈研发 / 项目负责人，不要反复试设置。

✅ 适用本指引（按设置即可改善）
  • 手机能收到税局验证码（普通短信），但 App 没有转发。
  • 退后台 / 息屏一段时间后掉线、无心跳、频繁离线。
  • App 进程被系统冻结、一键清理、杀后台。
  • 收到验证码但因双卡号码 / 卡槽识别问题没转发。
⛔ 不适用，需提单反馈研发 / 项目负责人
  • 按本指引全部设置并重启自测后，仍然收不到 / 不转发。
  • 手机根本收不到那条短信（系统"信息"里都找不到）——很可能是税局漏发 / 迟发，也可能是运营商、号码或收码卡问题。
  • 验证码只出现在无法关闭的"服务号 / RCS / 富媒体"会话里，关不掉。
  • App 闪退、崩溃、装不上、界面异常等程序问题。
  • 其它靠设置无法解决、疑似程序或服务端的问题。

零·附：华为 / 荣耀 鸿蒙（HarmonyOS）能否使用本 App

鸿蒙分两种，判断标准很简单：能不能装上本 App 的 APK —— 能装上就能正常使用（再按本指引设置），装不上就暂时用不了。先看 设置 → 关于手机 → 版本号。

✅ HarmonyOS 4.x 及更早（兼容安卓，可以用）

底层兼容安卓，可以直接安装 APK。只要能装上，就能正常使用，按本指引逐项设置即可。

⛔ HarmonyOS NEXT / 5.0（纯血鸿蒙，暂时无法使用）

纯血鸿蒙不再兼容安卓 APK，本 App 装不上、暂时无法使用。

替代方案：可联系账无忧客服 / 运营，了解「蒙柏接收器」或「虚拟号码」等其它验证码接收方式。

⚠️ 需要"提单"时，请提供以下材料

  1. 代账公司名称
  2. 手机号（收码卡号码）
  3. 实际收到、但 App 没检测到的税务短信截图 —— 最好带上具体时间
  4. 短信 App「设置」界面截图（如验证码保护 / 5G消息 等设置状态）等
  5. 简要情况描述（方便快速区分问题类型）：是 退后台 / 息屏一段时间后掉线、心跳中断（保活问题），还是 App 在线、但收到短信没转发 / 没检测到（短信检测问题）？

材料越齐全定位越快；短信截图最好能看清短信内容和到达时间。

一、短信相关设置

1. 关闭验证码保护 / 智能分类

  1. 打开系统"信息"App，点右上角菜单 / 更多 → 设置。
  2. 找到 验证码安全保护 / 隐私短信 / 智能分类 / 智能信息 等开关，全部关闭。
  3. 进"骚扰拦截 / 拦截设置"，确认没有把税局号码或验证码短信误拦、误分类到单独文件夹。

2. 关闭 5G 消息 / RCS / 增强消息（各品牌叫法不同，逐一排查）

同一个功能在不同手机里名字不一样，常见叫法有：5G消息、RCS、增强消息、增强短信、聊天功能、富媒体消息、服务消息、和信、飞信增强等。只要看到类似字样都应关闭，让验证码退回普通短信通道。

  1. 打开"信息"App → 右上角 菜单 / 更多 → 设置。
  2. 在设置里逐个查找并关闭下列任意存在的开关：
    • 5G消息 / RCS
    • 增强消息 / 增强短信 / 增强功能
    • 聊天功能 / Chat（RCS 聊天）
    • 富媒体消息 / 多媒体增强
    • 服务消息 / 服务号消息（若有单独的接收/展示开关）
  3. 信息设置里找不到时，再到系统设置里找：
    • 设置 → 移动网络 / SIM卡与流量管理 → 5G消息 / 增强消息
    • 用系统"设置"顶部搜索：分别搜 5G消息、增强消息、聊天功能、RCS，逐个进去关闭。
  4. 关闭后重启"信息"App 或手机，用新发的验证码测试（别用旧短信复测）。

补充：若验证码是落在"信息"里一个单独的 服务消息 / 服务号 / 公众号 会话（富媒体样式、非普通灰色短信），这属于非标准短信通道，关不掉的话本 App 读不到，需联系发送方改用普通短信下发，或反馈负责人。

3. 开启短信/电话/存储权限

  1. 进 设置 → 应用 → 报税助手 → 权限。
  2. 接收短信、读取短信：允许（若有"空白通行证"选项则关闭，选"始终允许"）。
  3. 读取电话状态、读取电话号码：允许。
  4. 存储 / 照片和视频：允许。

4. 核对收码卡号码

  1. 打开 报税助手 的号码 / SIM 设置界面。
  2. 确认接收验证码那张卡的号码已正确识别，且处于启用状态（双卡机注意别对错卡槽）。
  • 已关闭验证码保护 / 智能分类
  • 已关闭 5G消息 / RCS / 增强消息 / 聊天功能 等所有增强类开关
  • 短信 / 电话 / 存储权限已全部允许
  • 收码卡号码已核对、已启用

一·附：OPPO / 一加 / realme（ColorOS）短信检测设置图示（其他品牌路径类似，可对照）

下列为 OPPO 机型"信息"App 的实际设置界面，红框即需要开/关的项。核心是两件事：关闭 5G消息（让验证码走普通短信）、关闭智能信息服务里的"验证码安全保护"等（避免验证码被接管）。

二、保活设置（防止被冻结 / 被杀）

1. 允许自启动 / 后台运行

  1. 在系统设置搜索 "自启动" 或 "启动管理"，找到 报税助手。
  2. 若显示"自动管理"，先关闭"自动管理"，再把弹出的三项全部打开：允许自启动、允许关联启动、允许后台活动（后台运行）。
  3. 若只有一个"自启动"开关，直接打开。

2. 忽略电池优化 / 省电无限制

  1. 在设置搜索 "电池优化"，找到 报税助手，选 不允许优化 / 不限制。
  2. 再进 设置 → 应用 → 报税助手 → 电池 / 耗电，把省电策略设为 无限制。
  3. 关闭系统的 超级省电 / 极致省电 / 低电量省电 模式；关闭 睡眠模式 / 定时休眠；关闭 自适应电池 / 智能省电 对本 App 的限制。

3. 允许后台高耗电（部分机型单独一项，务必开）

很多手机（vivo/iQOO、部分华为荣耀等）在"忽略电池优化"之外，还单独有一项"后台高耗电 / 后台耗电管理 / 允许后台运行时高耗电"，不开就会被限。

  1. 在设置搜索 "后台耗电 / 高耗电 / 耗电管理"，或进 设置 → 电池 → 后台耗电管理（vivo 也可在"i 管家 → 应用管理 → 权限/耗电管理"里找）。
  2. 找到 报税助手，把 "允许后台高耗电 / 允许后台运行" 打开。

4. 防内存清理（加入"一直保留后台"名单）

部分机型会自动清理后台释放内存，需要把本 App 排除。

  1. 在设置搜索 "内存 / 后台管理 / 自动清理"，关闭 自动清理后台 / 内存加速 对本 App 的作用。
  2. 若有 "内存一直保留 / 全局后台 / 常驻后台 / 加速白名单" 名单，把 报税助手 加进去。

5. 息屏保持联网

  1. 进 设置 → WLAN → 更多设置 / 高级设置。
  2. 把 "休眠时保持 WLAN 连接" 设为 始终。
  3. 确认没有开启"省流量 / 流量节省"对本 App 的后台联网限制。

6. 锁定后台，不要手动清理

  1. 打开"最近任务"（多任务界面），找到 报税助手 卡片。
  2. 下拉或长按卡片 → 点锁图标 🔒 锁定，防一键清理误杀。
  3. 不要手动上划清理 报税助手（手动强杀后会失联，需重开 App）。

7. 通知权限 + 通知使用权

  1. 进 设置 → 通知 → 报税助手 → 允许通知（保留那条常驻通知，不要关）。
  2. 在设置搜索 "通知使用权"（或"通知读取"），找到 报税助手，打开。

8. 悬浮窗 / 后台弹出界面

  1. 进 设置 → 应用 → 报税助手 → 权限。
  2. 打开 显示悬浮窗 / 后台弹出界面。
  • 自启动 / 关联启动 / 后台活动 已全开
  • 已忽略电池优化 + 省电设为无限制（关超级省电/睡眠模式）
  • 已允许后台高耗电 / 后台耗电管理
  • 已防内存清理（加入一直保留后台 / 加速白名单）
  • WLAN 休眠保持连接 = 始终
  • 已锁定后台卡片，且不手动清理
  • 通知权限、通知使用权 已开启
  • 悬浮窗 / 后台弹出界面 已允许

下列为 vivo 机型的实际设置界面截图，红框即需要开/关的开关。其他品牌菜单名称不同，但对应的功能（后台高耗电、关闭省电、自启动等）是一样的，可参照上面第二节文字操作。

三、安卓 12 及以上追加设置

先看 设置 → 关于手机 的安卓版本，是 12 / 13 / 14 的再做本节。

  1. （安卓 13+）确保通知权限已允许（关了会导致常驻通知不显示）。
  2. 关闭"未使用应用移除权限 / 暂停应用活动"：进 设置 → 应用 → 报税助手 → 权限，把 "如果应用未使用则移除权限" 关掉。
  3. 若有 "闹钟和提醒" 权限项，允许 报税助手。
  • 通知权限已允许（13+）
  • 已关闭"未使用移除权限 / 暂停活动"
  • "闹钟和提醒"已允许（若有）

四、设置完成后的自测

  1. 重启手机一次。
  2. 打开一次 报税助手，确认能进主页、显示在线。
  3. 发一条测试短信到收码卡，确认能收到并转发（App 提示"验证码传输成功"）。
  4. 息屏 / 退后台等 10~15 分钟后再发一条，确认仍能收到、心跳没断。
  • 重启后已自测，短信能收到并转发
  • 息屏 10~15 分钟后仍正常

五、小结：这些设置到底在解决什么

本指引针对的是两类问题，做的所有设置都围绕它们展开：

① 短信检测问题（收到验证码，但 App 没转发 / 没检测到）

目的：让税局验证码以普通短信形式进入系统短信库，别被"验证码保护/智能分类"接管、也别走"5G消息/RCS/服务号"这类 App 读不到的通道；同时把短信、电话、通知等权限给全，让 App 的三条监听链路（短信数据库、短信广播、通知栏）能接收到。对应第一节及各品牌图示。

② 保活问题（退后台 / 息屏后掉线、无心跳、被冻结杀后台）

目的：把 App 加入系统各类白名单（自启动、后台高耗电、忽略电池优化、锁定后台、休眠保持联网等），并避免被一键清理和省电策略冻结，从而让后台进程长期存活、心跳持续在线。对应第二节及 vivo 图示。

一句话：让短信"进得来"，让 App"活得住"。短信进得来 + App 活得住 = 验证码稳定检测并转发。

注意：手机厂商的系统级限制无法被 App 100% 绕过，"手动强杀 / 被系统冻结"等场景无法保证绝不掉线，以上配置只能显著降低发生概率。若按本指引全部设置并重启自测后仍不行，或属程序 / 服务端问题，请按上方「⚠️ 需要提单时」的清单反馈研发。
